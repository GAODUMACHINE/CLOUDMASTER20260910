# 前端视觉风格设计（14 种，心理辅导适配）
> 注：#1 柔雾奶油已按需求停用并删除实现；编号保留以免打乱交叉引用。


> 配套 LightCloudMaster（18–25 岁青年 AI 心理陪伴）前端。

## 设计总原则（贯穿 14 种风格）
1. 安抚优先、去医学化：不做诊断/药方观感，语气与配色避免"病历/诊室"感。
2. 可信但不冰冷：有温度、可亲近，但保留边界（非真人/非医生声明）。
3. 安全第一：
   - 注册页严格执行年龄门（<14 强拒，文案明确）。
   - 未成年人进入"监护人可用"分支，界面更保守、更少诱导。
   - 危机(L2)升级与人工审核入口显著可寻，AI 标识（依赖倾向弹窗"内容由 AI 生成"）必现。
   - 隐私最小化视觉：不索要照片/真名/真实联络，输入框旁有"不记录真实身份"微文案。
4. 无障碍（WCAG AA）：色彩对比≥4.5:1、支持深/浅色、允许减弱动效(reduce-motion)、色弱安全配色。
5. 时间与陪伴感：让"时长守卫"以温柔而非惩罚的方式呈现。

## 2. 林间日光 Nature Daylight
- 心理定位：回归自然、安定呼吸。
- 色彩：#F1F6EE 底 / #7CA982 叶绿 / #D9B98C 木纹 / #47624F 深绿文字。
- 字体：中文字体配合植物感图标（树叶、呼吸圆）。
- 版式：顶栏留白，背景极淡叶片纹理（非动画或极慢）。
- 动效：深呼吸引导用收缩/扩张圆环，支持 reduce-motion 退化为静止。
- 适用：压力疏导、睡眠困扰会话。

## 3. 暖白留白 Warm Minimal
- 心理定位：编辑部式克制、值得信赖、不喧哗。
- 色彩：#FFFFFF 底 / #1E2A32 墨字 / #E4A85C 暖杏点缀 / #F4F0E9 卡片。
- 字体：衬线标题(思源宋)+无衬线正文，行距 1.8。
- 版式：杂志式分栏；危机区用固定侧条警示而非弹窗恐吓。
- 适用：成熟用户、需要边界感的会话；审计/隐私说明区。

## 4. 云朵玻璃 Cloud Glass
- 心理定位：轻盈、非正式、现代年轻感。
- 色彩：半透明玻璃卡片(backdrop-blur)+天空灰蓝底 #E8F1F8，点缀淡蓝 #7FB3D5。
- 字体：圆润无衬线。
- 版式：毛玻璃圆角卡片、柔和阴影，无硬边框。
- 动效：卡片微悬浮(<6px)、过渡 300ms；减少弹跳。
- 适用：18–22 年轻用户，聊天流、注册页。
- **v1.3 精修（「晨雾应用壳」，去 AI 生成感）**：保留磨砂玻璃材质与灰蓝天空，但玻璃是"材质"而非"造型"——
  - 骨架应用化：拒绝"居中悬浮玻璃大卡片"的营销页式样，改为真实应用壳——720px 栏宽、两侧发丝线；顶栏与输入坞是两条功能性磨砂条，聊天消息直接铺在天空上；
  - 色彩降饱和：晨雾三段 `#F6F9FB→#DEE8EF`，强调色收敛为单一墨蓝 `#2E5A7E`（AA/AAA）；
  - 细节安静化：不用宽字距标语/渐变/光晕；按钮小而实色（主按钮 42px 高， destructive 为陶土描边幽灵钮），"设置与资源"降级为输入坞旁的文字链；
  - 表单纸面化：注册/设置是平贴窄栏纸面（blur 14 + hairline + 极轻影），节标题发丝线 + 小号眉题；
  - 衬线仅用于品牌与标题（Georgia/宋体混排）；全页覆盖 ≈4.5% 颗粒噪点 + 极缓云雾漂移（140s，reduce-motion 静止）；
  - 危机横幅为暖纸色通告条 + 陶土左线；合规触点（AI 标识、年龄门、隐私微文案、reduce-motion）全部保留。

## 5. 纸感日记 Paper Journal
- 心理定位：私密书写感、鼓励表达。
- 色彩：米白纸 #FFFDF5 / 铅笔灰 #6E6E6E / 蓝墨水 #4A6FA5 / 手写体标题。
- 字体：标题手写/圆体，正文规整。
- 版式：信纸/日记布局，输入框像横线笔记本，历史会话像翻页。
- 动效：极轻墨迹渐显，无闪烁。
- 适用：表达型用户、情绪日记场景；未成年人保守分支也可。

## 6. 深夜蓝调 Night Indigo
- 心理定位：夜间/低唤醒，适合深夜情绪波动、失眠。
- 色彩：深蓝底 #1E2A4A / 低饱和文字 #C8D2E8 / 月白点缀 #F0F4FF。
- 字体：无衬线略细，暖光色温。
- 版式：深色主界面，夜间模式默认；按系统时间切换。
- 动效：极慢，无强闪烁。
- 适用：夜间会话、睡眠困扰；自动低光友好。

## 7. 呼吸渐层 Breath Gradient
- 心理定位：用渐变引导呼吸节奏。
- 色彩：柔和退晕背景(#D6ECD9→#CFE0F0 循环)，文字中性深灰。
- 字体：圆体。
- 版式：背景极慢呼吸色块(周期 8s)，内容居中一栏。
- 动效：呼吸色相是核心(可关闭)；减动效时静止为折中色。
- 适用：压力骤升、需要当即安抚的时刻。

## 8. 无障碍高对比 Accessible
- 心理定位：可访问性第一（近视觉/陪同者、弱对比困难者）。
- 色彩：纯白底/纯黑字，单一高对比强调 #005A9C；对比全部≥7:1。
- 字体：更大字号(基18px+)、行距 1.9、无衬线。
- 版式：线性单栏、明确焦点、全程键盘可导航。
- 动效：仅开关式，无背景动画。
- 适用：可切换的"无障碍模式"，与任一主风格并存。

## 9. 柔和赛博 Soft Cyber
- 心理定位：科技向善、智能体可信，面向对 AI 好奇的年轻用户。
- 色彩：深紫 #2B2D4F / 淡紫渐层 #7B6CF0→#A78BFA / 白字；压低霓虹浓度。
- 字体：半几何无衬线（略有科技感但不过载）。
- 版式：卡片+状态指示（"AI 正在思考"柔和光点）。
- 动效：数据流用柔和光晕，杜绝刺眼闪烁。
- 适用：注册页、流式 SSE 打字/思考反馈、AI 能力说明页。

## 10. 暖棉杂志 Editorial-Warm
- 心理定位：成熟、被照料、编辑部安抚文摘。
- 色彩：#FBEFE3 / #5A4632 可可字 / #C98A5A 陶土点缀。
- 字体：衬线大标题+舒适正文。
- 版式：杂志网格，科普条目(RAG 引用)以"编者注"卡片呈现、引用来源可见。
- 适用：知识科普/引用展示区、年龄偏大的青年用户。

## 11. 赤陶大地 Terracotta Earth
- 心理定位：接地、稳固、被托住。
- 色彩：#E8D8C8 砂 / #B0704A 赤陶 / #6E4F3A 褐字 / #D9E2CF 绿点缀。
- 字体：圆润无衬线。
- 版式：圆角块+陶土色主按钮("继续")，底栏信任信息。
- 动效：坚实、慢、无跳跃。
- 适用：需要"稳定依靠"感的用户、危机后的平静页。

## 12. 极光暮色 Aurora Dusk
- 心理定位：情绪流动性、包容差异。
- 色彩：深青→靛→粉的极慢极光渐变(#1C2B3A→#C25E8A)，文字暖白。
- 字体：圆体。
- 版式：全屏柔和极光(极慢)，对话悬浮卡片。
- 动效：极光低帧率呼吸；强减动效静止。
- 适用：情绪波动较大、需要"被包容"的会话；深色基调。

## 13. 水墨留白 Ink Minimal
- 心理定位：禅意、少即是多、冷静清醒。
- 色彩：#FAFAF7 宣纸 / #2A2A2A 墨 / 极少朱砂 #B04A3A 强调。
- 字体：毛笔/刚劲标题+细正文。
- 版式：大量留白，一行一句，慢速。
- 动效：无扰动画。
- 适用：清醒性疏导、专注呼吸、减少认知负荷。

## 14. 可爱伙伴 Friendly Buddy
- 心理定位：低龄/未成年亲切感，降低紧张。
- 色彩：#FFF6E9 奶底 / #F6B3C5 粉 / #8CC7B2 青绿 / 大圆角。
- 字体：圆体，偏大。
- 版式：温和非人形吉祥物（云朵/花，避免拟人过度），按钮文字化。
- 动效：吉祥物轻微呼吸浮动(可关闭)。
- 适用：未成年人专区（配合监护人可用信号）、初次使用引导。

## 15. 夜色包容 Dark Compassion
- 心理定位：深夜接纳、不评判的陪伴。
- 色彩：#14181F 深底 / #D8DEE9 灰白字 / 琥珀低饱和 #E0A96D。
- 字体：无衬线。
- 版式：深色全屏，弹窗极少；危机信息以"可获得的帮助入口"温柔高亮。
- 动效：极慢淡入，全站 reduce-motion 默认支持。
- 适用：夜间/低情绪会话；与 #6 深色互补(#6 偏蓝、本款偏中性暖)。

## 实现建议
- 主风格 + 无障碍切换(#8) 是最低要求；深色模式建议与任一浅色主风格成对。
- 危机(L2)/年龄门(<14)/邮箱HITL 三个 UI 触点必须在任何风格下都醒目合规。
- 所有动效均需 @media (prefers-reduced-motion: reduce) 退化。
- 图标与文案：避免"医院十字/胶囊/手术"；用"树叶、云朵、呼吸圆、书本、手捧"意象。
